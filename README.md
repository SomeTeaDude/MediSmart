# MediSmart

A site for medical purposes.

At the time i'm writing this, it's been around 2 years since i made this website, for someone who might not even remember me anymore.

Back then, I didn't know much about Next.js, so I thought it would be a good idea to create a simple landing page using it.

Now, two years later, when I look back at this project, I'm amazed by how precise I was when I was building it.

## About

This is a [Next.js](https://nextjs.org) (v15) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
